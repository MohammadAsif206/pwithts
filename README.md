# 🎭 Playwright Automation Project (TypeScript)

This project contains end-to-end (E2E) test automation using **Playwright** with **TypeScript**, targeting the demo application:  
👉 https://valentinos-magic-beans.click

---

## 🚀 Project Overview

The goal of this project is to practice and demonstrate modern UI automation techniques using Playwright, including:

- Browser automation (Chromium, Firefox, WebKit)
- UI interaction and validation
- Reliable selectors and locators
- Test structuring and reusability
- Handling dynamic elements and waits
- Debugging and reporting

---

## 🛠️ Tech Stack

- Playwright  
- TypeScript  
- Node.js  
- VS Code
